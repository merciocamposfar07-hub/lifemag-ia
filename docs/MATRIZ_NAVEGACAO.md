# Matriz de navegação
| Área | Acesso | Objetivo |
|---|---|---|
| Nova formulação | Cartão Home | Criar atendimento e abrir Conversa Inteligente |
| Pacientes | Cartão Home | Cadastro e histórico |
| Minhas fórmulas | Cartão Home | Lista e versões |
| Receituário | Cartão Home | Emissão demonstrativa |
| Acompanhar | Barra inferior | Alertas, retornos, evolução |
| IA | Barra inferior (centro) | Abrir Conversa Inteligente; modelo de IA ainda não integrado |
| Simulador | Editor Studio Magistral / menu lateral desktop | Comparação de versões |
| Ciência | Barra inferior | Fontes e futuras atualizações |
| Documentos | Barra inferior | Ficha, declarações e protocolo |
Barra inferior móvel: **Início → Acompanhar → IA → Ciência → Documentos**. O botão IA tem destaque visual e acesso à Conversa Inteligente, mas não executa modelo de linguagem sem backend e integração autenticada.

Não criar segunda rota com botão diferente para a mesma função na Home.
